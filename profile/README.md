# Sony Xperia SM8650 Recovery

Custom recovery for Sony Xperia devices on the Qualcomm SM8650
(Snapdragon 8 Gen 3) platform: OrangeFox (`android-14.1-fox`, default) and
TWRP (`android-12.1`).

## Devices
- Xperia 1 VI (`pdx245`, SM8650): [device_sony_pdx245-TWRP](https://github.com/sony-sm8650-TWRP/device_sony_pdx245-TWRP)
  - OrangeFox: branch `android-14.1-fox`
  - TWRP: branch `android-12.1`

## Building
See [local_manifests](https://github.com/sony-sm8650-TWRP/local_manifests): branch `android-14.1-fox` for OrangeFox (default), `android-12.1` for TWRP 12.1.
